# 分层堆瓷配色与透光预览系统

浏览器端全光谱牙冠配色工作台，TypeScript + 原生 WebGL2，病例数据仅存本机 IndexedDB，无后端依赖。

## 核心能力

- 全光谱管线：380–780nm 共 41 个波段，CIE 1931 配色函数 + 四种光源 SPD，光谱 → XYZ → Lab 全程计算
- Kubelka-Munk 多层漫射光学：牙本质/切端/透明/效果四层瓷粉叠层合成，数值稳定的 Rb/T 归一化形式（经 RK 数值积分逐点验证）
- 实时渲染：KM 叠层预计算为 32³ 三维 LUT，改厚度只走纹理采样，厚度调整即时刷新
- 次表面散射与切端乳光：背光透射项 + Rayleigh 瑞利散射，暗口腔背景联动
- 比色对照：D65 下与 VITA 16 色板对比，CIEDE2000 色差分区读数 + 模型热力图
- 同色异谱：日光/标准灯/诊室 LED/手机闪光灯四光源切换
- 反算推荐：坐标下降求各层三分区厚度，输出遮色保守/均衡/通透三套方案
- 制作单：烧结收缩率补偿后的堆塑厚度、烧成次数，可直接打印

## 颜色准确度

D65 标准光源下，标定后的默认叠层与目标色号 A2 的 ΔE2000 = 0.42（要求 < 2）。
反算器最优方案 ΔE2000 ≤ 1.5。运行 `pnpm selftest` 可复现全部光学验证。

## 启动

```bash
pnpm install
pnpm dev
```

浏览器打开 http://localhost:5180 。建议使用 Chrome/Edge 最新版（需 WebGL2 与 EXT_color_buffer_float）。

## 其他命令

```bash
pnpm selftest   # Node 光学管线自检，无需浏览器
pnpm build      # 类型检查 + 生产构建
```

## 目录结构

```
src/
  core/         # 光谱数学、KM 光学、STL、牙冠网格、FDI 牙位
  render/       # WebGL2 渲染器、GLSL 着色器、3D LUT 构建
  state/        # IndexedDB 存储、全局状态、渲染会话、种子病例
  pages/        # 七个页面
  ui/           # DOM 辅助、路由、3D 画布、图标、设计系统
```

## 标定说明

瓷粉的吸收 K/散射 S 以基函数系数存于瓷粉库（`src/core/materials_data.ts`），
可在「瓷粉库」页面编辑。修改参数后所有病例的光学 LUT 自动重建。
真实投产时建议用分光光度计测量各品牌色号的反射率/透射率，替换标定值。
